# School Management System

## Introduction

This project is a simple School Management System developed using Python. Its purpose is to manage different parts of a school, including students, teachers, courses, and classrooms.

The program uses an object-oriented approach, with separate classes for each main component of the school. This makes the code more organized and easier to maintain.

## Features

- Student Management: Add, edit, delete, and view students.
- Teacher Management: Add, edit, delete, and view teachers.
- Course Management: Create, edit, delete, and view courses.
- Classroom Management: A planned feature for organizing classrooms, teachers, and students.
- Data Storage: Save and load information using JSON files.
- Course Selection: Assign courses to individual students.

## Technologies

- Python
- Object-Oriented Programming (OOP)
- JSON

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Make sure "data.json" is in the project directory.
4. Run the Python file.
